# راهنمای طراحی و توسعه بر پایهٔ Fuwari

رابط سایت با الهام از زبان بصری مجله‌های دیجیتال و با اقتباس اولیه از قالب متن‌باز [Fuwari](https://github.com/saicaca/fuwari) بازآرایی شده است. چیدمان فعلی بر تایپوگرافی بزرگ، فضای سفید، معرفی برجستهٔ یک مقاله، شبکهٔ نامتقارن نوشته‌ها و تأکیدهای محدود فیروزه‌ای و یاقوتی تکیه دارد. محتوا و مسیرهای سایت متعلق به پروژهٔ سینا یعقوبی‌اند و هیچ چارچوب یا مسیر مسیریابی دیگری جایگزین Astro نشده است. متن مجوز اقتباس در [اعلان مجوزهای ثالث](../THIRD_PARTY_NOTICES.md) آمده است.

## معماری و فایل‌های اصلی

- پروژه همچنان Astro با خروجی Static است؛ Content Collection فعلی در `src/content.config.ts` و نوشته‌ها در `src/content/materials/` باقی مانده‌اند.
- مسیر مقاله‌ها `/materials/[slug]/` و مسیرهای بخش‌ها `/psychoanalysis/` و `/philosophy/` حفظ شده‌اند. مسیر `/archive/` برای فهرست همهٔ نوشته‌ها اضافه شده است.
- `src/components/MainGridLayout.astro` پوستهٔ مشترک نوار ناوبری، محتوای صفحه و پابرگ را فراهم می‌کند؛ معرفی ویژهٔ صفحهٔ اصلی در `src/pages/index.astro` قرار دارد.
- `src/components/PostCard.astro` کارت‌های تحریریه‌ای نوشته‌ها را می‌سازد و `src/components/TOC.astro` فهرست مطالب مقاله را فراهم می‌کند.
- توکن‌های طراحی، RTL، رفتار واکنش‌گرا و حالت تیره در `src/styles/global.css` نگهداری می‌شوند.
- تنظیمات `wrangler.jsonc`، Astro و گردش‌کار انتشار Cloudflare تغییر نکرده‌اند.

## سیستم طراحی و تایپوگرافی

پس‌زمینه در حالت پیش‌فرض سفید است؛ ذغالی برای متن، فیروزه‌ای برای تعامل‌ها و یاقوتی برای تأکیدهای محدود استفاده می‌شود. رنگ‌ها، عرض محتوای صفحه و متن، و پس‌زمینهٔ حالت تیره در بالای `src/styles/global.css` به‌صورت متغیر CSS تعریف شده‌اند. صفحهٔ خانه و کارت‌های منتخب از شبکهٔ نامتقارن و تصویرهای انتزاعی محلی استفاده می‌کنند؛ صفحهٔ مقاله عرض خواندن مستقل و فهرست مطالب دارد. اندازهٔ پایهٔ متن رابط ۱۶ پیکسل است و تیترها به‌صورت سیال با عرض نمایشگر تغییر می‌کنند؛ عرض خواندن مقاله حداکثر ۷۴۰ پیکسل است.

- Estedad فونت اصلی رابط و متن است؛ Markazi Text برای نقل‌قول‌ها و موارد ادبی در دسترس است.
- فونت‌ها محلی و در `public/fonts/` نگهداری می‌شوند؛ مجوزهای OFL آن‌ها نیز کنار فایل‌ها قرار دارند. فونت یا CDN خارجی اضافه نشده است.
- حالت روشن پیش‌فرض است. دکمهٔ نوار بالا انتخاب حالت تیره را در مرورگر ذخیره می‌کند.
- انیمیشن ورود، حرکت نوار تحریریه‌ای، نمایش تدریجی تصویرها و پارالاکس محدود با CSS و APIهای بومی مرورگر ساخته شده‌اند؛ وابستگی انیمیشن جدیدی اضافه نشده است.
- `prefers-reduced-motion` رعایت می‌شود و حرکت‌های غیرضروری کاهش می‌یابند.

## آیکون‌ها

آیکون‌های رابط از وابستگی موجود `@lucide/astro` می‌آیند و به‌صورت SVG رندر می‌شوند؛ نیازی به درخواست خارجی یا runtime جداگانه نیست:

```astro
---
import { ArrowLeft } from '@lucide/astro';
---

<ArrowLeft size={18} aria-hidden="true" />
```

آیکون تزئینی باید `aria-hidden="true"` داشته باشد. کنترل آیکون‌محور باید نام دسترس‌پذیر مانند `aria-label` داشته باشد.

## تصویرها و محتوای Markdown

- تصویرهای مقاله در `public/images/articles/` و تصویر بنر در `public/images/hero/` نگهداری می‌شوند. مسیرها از فرانت‌متر مقاله خوانده می‌شوند.
- برای تصویر مقاله از `cover` و `coverAlt` موجود استفاده کنید؛ متن جایگزین باید توصیف واقعی تصویر باشد. تصاویر کارت‌ها با `loading="lazy"` و ابعاد مشخص بارگذاری می‌شوند.
- هنگام افزودن Markdown، schema فعلی شامل `title`، `description`، `section`، `publishedAt` اختیاری، `cover`، `coverAlt`، `tags` و `draft` است. فقط دو مقدار `psychoanalysis` و `philosophy` برای `section` معتبرند.
- تاریخ انتشار اختیاری است؛ در نبود آن تاریخ ساخته یا حدس زده نمی‌شود.
- `public/uploads/` و همهٔ تصویرها و مقالات قبلی حفظ شده‌اند؛ هیچ محتوای مقاله بازنویسی نشده است.

## قابلیت‌ها و وابستگی‌های مرتبط

- Tailwind CSS 3 از طریق `postcss.config.mjs` به‌صورت مستقیم به زنجیرهٔ PostCSS متصل است. از `@astrojs/tailwind` استفاده نشده، چون نسخهٔ upstream بررسی‌شده peer requirement سازگار با Astro 7 ندارد.
- سبک Markdown با CSS همین پروژه تنظیم شده است تا وابستگی تایپوگرافی دیگری لازم نباشد.
- Pagefind جست‌وجوی محلی و ایستای بدون API را فراهم می‌کند. `npm run build` ابتدا Astro را می‌سازد و سپس شاخص جست‌وجو را در `dist/pagefind/` می‌سازد. در سرور توسعه، چون این شاخص هنوز ساخته نشده، پنجرهٔ جست‌وجو پیام محدودیت نسخهٔ توسعه را نمایش می‌دهد.
- Svelte، Swup، CMS، سرویس ابری جست‌وجو، کلید API و وابستگی‌های خارج از نیاز اضافه نشده‌اند.

## تست، Build و انتشار

فرمان یکپارچهٔ بررسی‌ها:

```sh
npm run validate
```

فرمان‌های تفکیک‌شده:

```sh
npm run check
npm run lint
npm run format:check
npm run test
npm run test:e2e
npm run build
npm run preview
```

Playwright برای آزمون مسیرها، منوی موبایل، حالت تیره، جست‌وجو و اندازه‌های واکنش‌گرا استفاده می‌شود؛ `@axe-core/playwright` نیز صفحات را از نظر دسترس‌پذیری می‌سنجد. Build در `dist/` باقی می‌ماند و Pagefind نیز همان‌جا فایل‌های جست‌وجو را تولید می‌کند. `npm run preview` برای آزمون رفتار جست‌وجوی نسخهٔ ساخته‌شده مناسب است.

انتشار همچنان به Git integration فعلی Cloudflare واگذار شده است. Workflow گیت‌هاب فقط اعتبارسنجی و Build انجام می‌دهد و deploy نمی‌کند؛ هیچ Secret یا توکن Cloudflare برای این روند لازم نیست. نام Worker، شاخهٔ `main`، `wrangler.jsonc`، مسیر دارایی‌های Static و دستورات انتشار تغییر نکرده‌اند.

## مواردی که همچنان نیازمند بررسی‌اند

- جست‌وجوی Pagefind در Build/Preview یا سایت منتشرشده کار می‌کند، نه روی سرور توسعهٔ معمولی.
- URL رسمی سایت در پیکربندی Astro تعیین نشده است؛ بنابراین canonical کامل و sitemap متکی بر دامنهٔ حدس‌زده‌شده ساخته نشده‌اند.
- صحت علمی و منبع‌دهی مقاله‌ها و تناسب متن جایگزین تصویرها همچنان به بازبینی انسانی نیاز دارد.
